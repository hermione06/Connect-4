# Connect 4 Game in C

## Overview

This is a **Connect 4** game written in C where a human player competes against a computer opponent. The computer is designed to make smart moves, providing a challenging experience for the player. The game uses a 7-column, 6-row vertically suspended grid, and the objective is to connect four discs in a row—horizontally, vertically, or diagonally—before the opponent does.

## Features

- Human vs. Computer gameplay.
- The computer uses algorithms to generate smart moves.
- Command-line interface for easy interaction.
- Input validation to handle invalid moves.
